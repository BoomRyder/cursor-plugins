# Cursor Plugins

个人 Cursor 插件市场。在 Customize 里用 **Add Marketplace → Import from GitHub** 导入本仓库，然后安装需要的插件。

| 插件 | 上游 | 内容 |
| --- | --- | --- |
| [ponytail](https://github.com/DietrichGebert/ponytail) | Dietrich Gebert，MIT | 用最少的代码把事情做完 |
| [superpowers](https://github.com/obra/superpowers) | Jesse Vincent，MIT | TDD、调试和协作流程 |
| [document](https://github.com/anthropics/skills) | Anthropic，Apache-2.0 | Word、PDF、PowerPoint、Excel |
| [aihero](https://github.com/mattpocock/skills) | Matt Pocock，MIT | 规格、工单、TDD、代码评审 |

各插件的内容保持上游原文，许可证和版权也随原文件保留。本仓库自己的说明和市场清单使用 MIT。

## 安装

1. 打开 Customize。
2. 点 **Add Marketplace**，选 **Import from GitHub**。
3. 填入本仓库地址。
4. 安装 **Ponytail**、**Superpowers**、**Document** 或 **AI Hero**。
5. 执行 **Developer: Reload Window**。
